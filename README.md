# H_nt3r

Personal hub: links, visuals, and things to download or buy. Plain static site (no build step).

- `index.html` — the whole page
- `assets/video`, `assets/poster` — web-sized loops made from TouchDesigner renders
- `make-loops.sh` — builds seamless, silent, ~2 MB loops + posters from source renders (needs `.tools/ffmpeg`, which is gitignored)
